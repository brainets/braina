# Directed Connectivity Analysis (Granger Causality) Summary

This document summarizes the steps and results of the directed connectivity analysis performed using the `frites` toolbox.

## 1. Data Generation
A simulated dataset was generated using an autoregressive (AR) model with the following parameters:
- **Type**: `hga` (High-Gamma Activity)
- **Epochs**: 50
- **Time Points**: 300
- **Tool used**: `frites_sim_ar`

The output was saved to `sim_ar_data.nc`.

## 2. Connectivity Estimation
Covariance-based Granger Causality (CovGC) was computed to estimate directed influence between simulated regions:
- **Time Window (dt)**: 10 samples
- **Lag**: 2 samples
- **Time Points (t0)**: [100, 150, 200]
- **Tool used**: `frites_conn_covgc`

The results were saved to `gc_result.nc`.

## 3. Visualization
A heatmap was generated to visualize the mean directed connectivity matrix across trials and time points.
- **Script**: `plot_gc.py`
- **Output Image**: `gc_heatmap.png`

The heatmap shows the strength of directed interactions (e.g., `x -> y` and `y -> x`) recovered from the simulated AR model.
